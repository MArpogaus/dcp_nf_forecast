** About The Project

Probabilistic multi-step time series forecasting using normalizing flows.
Each target variable gets its own univariate model (Bernstein polynomial or
rational quadratic spline MAF). The data pipeline supports configurable lag
features, sin/cos time encoding, and temporal train/val/test splits.

*** Input Data (X)
- *Arbitrary tabular covariates* – static per-timestep columns passed through as-is.
- *Sin/cos encoded time/date variables* – configurable frequencies for time-of-day, day-of-week, day-of-year.
- *Configurable lag features* – independent history lengths per column, e.g. 96 steps of the target + 48 steps of a related covariate.

*** Output Data (Y)
- *Multi-step forecast horizon* – future values of a single target column, configurable horizon length.

The pipeline is orchestrated with *DVC* using =foreach= over the four
targets (=dla=, =ofen_g_koks=, =ofen_f_koks=, =pl2=). All intermediate and
processed data uses the feather format for fast I/O.

** Getting Started

*** Installation

This project uses [[https://docs.astral.sh/uv/][uv]] for dependency management
and [[https://direnv.net/][direnv]] for automatic virtual environment activation.

#+begin_src bash
# clone the repository
git clone <repo-url>
cd dcp-nf-forecast

# allow direnv to activate the venv
direnv allow

# install the package and all dependencies
uv sync
#+end_src

*** Running the Pipeline

The DVC pipeline consists of two stages per target (8 total):

#+begin_src bash
dvc repro
#+end_src

This executes:

1. *prepare* – loads the raw CSV, builds time features, lag features, and
   target matrix, validates, saves to =data/interim/<target>/=.
2. *split* – loads interim X/y, splits temporally into train/val/test,
   saves to =data/processed/<target>/=.

Each stage can also be run directly:

#+begin_src bash
python scripts/prepare_features.py \
  --raw-data-path <path> \
  --datetime-column new_time \
  --fillna-method ffill \
  --tabular-covariate-columns ofen_g_koks_kg ofen_f_koks_kg pl2_stromverbrauch_kwh \
  --time-component time:4 \
  --time-component day_of_week:4 \
  --time-component day_of_year:4 \
  --target-config params/targets/dla.yaml \
  --output-dir data/interim/dla \
  --data-format feather \
  --log-level info \
  --log-file logs/pipeline.log
#+end_src

All CLI arguments are mandatory and carry no defaults. The scripts are fully
decoupled from the DVC API – they read no params files internally.
