** About The Project

Probabilistic multi-step time series forecasting using normalizing flows.
Each target variable gets its own univariate model with one of three base
distributions: Normal, TruncatedNormal(0,5), or LogNormal. The flow
architecture is a one-layer Masked Autoregressive Flow (MAF) with optional
Scale and Shift bijectors, paired with either:

- *Rational Quadratic Spline* (RQS) — 12-bin spline with domain matching
  the base distribution support, or
- *Bernstein Polynomial* — 16-degree polynomial with configurable domain.

17 model variants are trained and evaluated per target. All experiments
are tracked via MLflow.

** Model Variants

| Variant | Base Distribution | Bijector(s) | Scale Constraint | Shift Constraint |
|---------+-------------------+-------------+------------------+------------------|
| normal_baseline | Normal(0,1) | Diagonal | — | — |
| truncated_baseline | TruncatedNormal(0,5) | Diagonal | — | — |
| lognormal_baseline | LogNormal(0,1) | Diagonal | — | — |
| spline_nf | Normal(0,1) | RQS (8-bin) | — | — |
| spline_nf_truncated | TruncatedNormal(0,5) | RQS (8-bin) | — | — |
| spline_nf_lognormal | LogNormal(0,1) | RQS (24-bin) | — | — |
| spline_nf_scale | Normal(0,1) | Scale + RQS | softplus | — |
| spline_nf_scale_truncated | TruncatedNormal(0,5) | Scale + RQS | [0.3, 1.0] | — |
| spline_nf_scale_lognormal | LogNormal(0,1) | Scale + RQS | [0.3, 1.0] | — |
| spline_nf_scale_shift | Normal(0,1) | Scale+Shift+RQS | softplus | softplus |
| spline_nf_scale_shift_truncated | TruncatedNormal(0,5) | Scale+Shift+RQS | [0.3, 1.0] | (-0.5, 0) |
| spline_nf_scale_shift_lognormal | LogNormal(0,1) | Scale+Shift+RQS | [0.3, 1.0] | (-5, 0) |
| bernstein_nf | Normal(0,1) | BernsteinPolynomial | — | — |
| bernstein_nf_truncated | TruncatedNormal(0,5) | BernsteinPolynomial | — | — |
| bernstein_nf_lognormal | LogNormal(0,1) | BernsteinPolynomial | — | — |
| bernstein_nf_scale | Normal(0,1) | Scale + Bernstein | softplus | — |
| bernstein_nf_scale_truncated | TruncatedNormal(0,5) | Scale + Bernstein | [0.3, 1.0] | — |
| bernstein_nf_scale_lognormal | LogNormal(0,1) | Scale + Bernstein | [0.3, 1.0] | — |
| bernstein_nf_scale_shift | Normal(0,1) | Scale+Shift+Bernstein | softplus | softplus |
| bernstein_nf_scale_shift_truncated | TruncatedNormal(0,5) | Scale+Shift+Bernstein | [0.3, 1.0] | (-0.5, 0) |
| bernstein_nf_scale_shift_lognormal | LogNormal(0,1) | Scale+Shift+Bernstein | [0.3, 1.0] | (-5, 0) |

Spline domain = [range_min, range_min + interval_width]:
- Normal: [-5, 5] (range_min=-5, interval_width=10)
- TruncatedNormal(0,5): [0, 5] (range_min=0, interval_width=5)
- LogNormal(0,1): [exp(-5), exp(5)] (range_min=exp(-5), interval_width≈148.4)

** Pipeline

The DVC pipeline handles all 68 stages (17 models × 4 targets):

#+begin_src bash
# Full pipeline
dvc repro

# Individual stages
dvc repro prepare@0 split@0                    # data for DLA
dvc repro train@dataset0-spline_nf              # train on DLA
dvc repro evaluate@dataset0-spline_nf           # evaluate on DLA

# Parallel multi-GPU evaluation
bash scripts/dvc_repro_parallel.sh
#+end_src

Per-target configuration is stored in =params.yaml=. Each target entry
specifies its own covariates, lag/lead features, NaN handling, and
prediction horizon.

** Getting Started

#+begin_src bash

direnv allow
uv sync
#+end_src

#+begin_src bash
uv run pytest --cov

#+end_src

** NaN Filling

Missing values can be filled with a constant plus optional noise
(=lognormal=, =uniform=, etc.). Configured per-target in =params.yaml=.
